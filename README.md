# 🪙 Crypto Cards — крипто-дашборд на Next.js + Web3

<img width="1933" height="1036" alt="crptcrd" src="https://github.com/user-attachments/assets/676cfe94-ebc1-4415-a458-58672739e039" />

**Crypto Cards** — учебное web3-приложение для просмотра криптовалютного рынка и взаимодействия со смарт-контрактом через MetaMask.  
Проект построен на **Next.js**, **React**, **TypeScript**, **ethers.js** и **Three.js**: приложение показывает актуальные цены монет, визуализирует рынок в 3D-сцене и позволяет пользователю сохранять выбранные crypto cards в смарт-контракте Sepolia.

---

### 🔗 Демо

Проект запускается локально:

```bash
npm run dev
```

После запуска приложение доступно по адресу:

```text
http://localhost:3000
```

## ⭐ Основные фичи

### 1️⃣ Криптовалютный дашборд

- Получение актуальных цен через локальный API route
- Отображение карточек Bitcoin, Ethereum, Solana и Toncoin
- Показ цены, тикера и изменения стоимости
- Ручное обновление данных без перезагрузки страницы

---

### 2️⃣ Страница отдельной монеты

- Динамический маршрут `/coins/[symbol]`
- Проверка существования монеты
- Отдельные состояния загрузки и 404
- Переход к деталям монеты из общей карточки

---

### 3️⃣ 3D-визуализация рынка

- Интерактивная сцена на **Three.js**
- Размер и цвет объектов зависят от рыночных данных
- Визуальная группировка монет по текущему изменению цены
- Клиентская загрузка сцены без SSR, чтобы Next.js не ломался на browser-only API

---

### 4️⃣ Подключение MetaMask

- Подключение кошелька через `window.ethereum`
- Отображение адреса, сети и баланса
- Реакция на смену аккаунта и сети в MetaMask
- Проверка, что пользователь находится именно в **Sepolia**

---

### 5️⃣ Смарт-контракт CryptoCards

Смарт-контракт хранит список карточек, созданных конкретным адресом кошелька.

В контракте есть:

- `mintCard(symbol)` — создает карточку выбранной монеты
- `getMyCards()` — возвращает карточки текущего пользователя
- `getCardsByUser(address)` — возвращает карточки любого указанного адреса
- `CardMinted` — событие, которое срабатывает после создания карточки

Контракт развернут в тестовой сети **Sepolia**, поэтому реальные деньги в проекте не используются.

---

### 6️⃣ Crypto Cards пользователя

- Пользователь подключает MetaMask
- Выбирает монету и нажимает `Collect`
- Подтверждает транзакцию в MetaMask
- После подтверждения карточка появляется в блоке **My Crypto Cards**
- Повторное создание уже сохраненной карточки блокируется на стороне приложения

Проект использует тестовую сеть **Sepolia**.
